# 🧮 Calculadora em Python

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido como parte dos meus estudos iniciais em lógica de programação e Python, dentro do curso de Análise e Desenvolvimento de Sistemas. O objetivo é criar um programa simples que realize as quatro operações matemáticas básicas (soma, subtração, multiplicação e divisão), aplicando na prática os primeiros conceitos fundamentais da linguagem: entrada e saída de dados, variáveis e conversão de tipos.

## 🛠️ Tecnologias utilizadas

- **Python 3** — linguagem utilizada para desenvolver toda a lógica do programa
- **VS Code** — editor de código utilizado no desenvolvimento

## ⚙️ Como funciona

O programa solicita ao usuário dois números através da função `input()`, convertendo os valores digitados (que originalmente são texto/string) para números inteiros com `int()`. Em seguida, realiza as quatro operações matemáticas utilizando os operadores `+`, `-`, `*` e `/`, exibindo os resultados na tela com a função `print()`.

## 📚 O que foi aprendido

Consolidei a diferença entre **string** (texto) e **número**, entendendo por que é necessário converter o valor retornado pelo `input()` usando `int()` antes de realizar operações matemáticas. Também aprendi a reaproveitar variáveis já preenchidas em vez de solicitar os mesmos dados repetidamente ao usuário.

## 🚀 Próximos passos

Pretendo evoluir este projeto adicionando tratamento de erros (como divisão por zero) e transformando as operações em funções separadas, à medida que avanço nos estudos.
